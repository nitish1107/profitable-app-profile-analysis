⚡ Live SQL Query Execution & Code Diff
🛑 Baseline SQL (Unoptimized):
SELECT a.app_id, a.app_name, a.total_est_revenue FROM apps_flat a WHERE a.has_in_app_purchases = 1 AND a.total_est_revenue > ( SELECT 1.5 * AVG(sub2.total_est_revenue) FROM apps_flat sub2 WHERE sub2.category = a.category );
🟢 Optimized SQL (Window Functions + CTE):
WITH categorized_freemium AS ( SELECT app_id, app_name, total_est_revenue, AVG(total_est_revenue) OVER (PARTITION BY category) AS cat_avg FROM apps_flat WHERE has_in_app_purchases = 1 ) SELECT app_id, app_name, total_est_revenue FROM categorized_freemium WHERE total_est_revenue > (1.5 * cat_avg);
